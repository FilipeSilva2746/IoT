# ESP32 Cardiac Monitor

Sistema IoT para monitoramento cardíaco remoto usando ESP32 e AD8232.

## Descrição
Este projeto propõe um sistema baseado em IoT para monitoramento remoto de eletrocardiograma (ECG) utilizando o sensor AD8232 e o microcontrolador ESP32. O sistema coleta dados em tempo real dos pacientes, transmite-os para uma plataforma em nuvem para análise e gera alertas em caso de irregularidades, visando aprimorar o monitoramento da saúde, especialmente de populações vulneráveis em áreas remotas.

Inspirado no Objetivo de Desenvolvimento Sustentável 3, o projeto aborda desafios no acesso à saúde ao possibilitar a supervisão contínua dos pacientes, reduzir a necessidade de visitas frequentes aos hospitais e promover a detecção precoce de problemas cardíacos.
